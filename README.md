# Clip'n'Note

A browser notepad that lets users write and save text notes, then find them again without leaving the current tab. 

## What's New in 2.1

- ✨ The scratch pad can be saved as a note with **Save as note**. The first line becomes the note's name, the rest its content, and the scratch pad is cleared. **Undo** puts the text back.
- 🐛 **New note** now always opens a blank note. It no longer copies the current page's title and link.

## Key Features

- A scratch pad for quick text, saved automatically while typing and turned into a note in one click
- Notes that can be searched by keyword and copied to the clipboard in one click
- Automatic sync across signed-in browsers, with no separate account

## How to Use

1. Click the Clip'n'Note icon in the toolbar.
2. Click **New note** to start a blank note, or click **Save as note** to turn the scratch pad into one.
3. Type in the search box and press **Enter** to copy the newest matching note.

## Privacy

The extension sends nothing anywhere and has no server. Notes are stored by the browser and synced through the browser account.

Full details: [privacy policy](PRIVACY.md).

## Compatibility

Compatible with most Chromium-based browsers, including Google Chrome, Microsoft Edge and Vivaldi.
